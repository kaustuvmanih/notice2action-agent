           Notice2Action Agent Architecture & Prompt Specs
        

        
      

      

        

          

             1. XML Sandboxing Defense
          

          
All document text is sanitized of control characters and wrapped inside strict <untrusted_document_content> tags. The model is primed with passive-data rules preventing prompt injection and role hijacking.

        

        

          

             2. Mandatory Verbatim Quote Grounding
          

          
Extracted deadlines and rules must cite an exact verbatim_quote and 1-indexed page_number, which is verified programmatically by the Step 3 Deterministic Verifier.

        

        

          

             3. Automated Cross-Document Conflict Audit
          

          
The Step 4 auditor scans for CGPA thresholds, income caps, expired caste certificates, and missing attachments to prevent rejection before portal submission.
